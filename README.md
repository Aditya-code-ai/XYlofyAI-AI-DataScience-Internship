# 📌 Internship Projects

---

## 🏠 Week 1 — House Price Prediction

### Objective

Build a Machine Learning model capable of predicting house prices using property features such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Furnishing Status
- Location Features

### Workflow

✔ Data Cleaning

✔ Feature Engineering

✔ Exploratory Data Analysis

✔ Linear Regression

✔ Random Forest Regressor

✔ Model Evaluation

### Evaluation Metrics

- MAE
- RMSE
- R² Score

### Visualizations

- House Price Distribution
- Correlation Heatmap
- Actual vs Predicted Prices

---

## 👨‍💼 Week 2 — Employee Attrition Prediction

### Objective

Predict whether an employee is likely to leave the company using HR Analytics data.

### Workflow

✔ Data Preprocessing

✔ One-Hot Encoding

✔ Feature Scaling

✔ Logistic Regression

✔ Random Forest

✔ Gradient Boosting

✔ Feature Importance Analysis

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

### Business Insights

- Attrition by Department
- Attrition by Job Role
- Income vs Attrition
- Work-Life Balance Analysis

---

## 📈 Week 3 & Week 4 — End-to-End Sales Forecasting & Demand Intelligence System

### Objective

Develop a production-style Sales Forecasting platform capable of predicting future sales, detecting anomalies, and providing business insights through an interactive Streamlit dashboard.

### Features

✔ Time Series Analysis

✔ SARIMA Forecasting

✔ Facebook Prophet

✔ XGBoost Forecasting

✔ Isolation Forest

✔ Z-Score Anomaly Detection

✔ K-Means Clustering

✔ Product Demand Segmentation

✔ Streamlit Dashboard
